Manager portraits folder
=======================

Place your custom manager portrait here:

- lord.png   -- Used when your title is "Lord" (or default)
- lady.png   -- Used when your title is "Lady"

Recommended size: 256x256 pixels. The game will scale the image to fit.

If you do not place any file here, the character sheet will show "No portrait"
until you add lord.png or lady.png. You can create these images yourself or
use the standard ones provided by the game.
