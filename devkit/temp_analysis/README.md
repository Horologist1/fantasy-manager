# Análisis Temporales

Esta carpeta contiene análisis temporales y documentos de referencia creados durante el desarrollo.

**Nota:** Esta carpeta está configurada para ser ignorada por Ren'Py al crear releases.

## Contenido

- Análisis de imágenes faltantes por folder (aspen, florian, ravengirl, redgirl)
- Comparaciones y rankings de folders
- Cálculos de nivelado de habilidades
- Verificaciones de completitud

Estos archivos son temporales y pueden ser eliminados o reorganizados según sea necesario.
