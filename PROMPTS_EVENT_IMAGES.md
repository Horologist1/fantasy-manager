# Prompts para Imágenes de Eventos (Backgrounds, Success, Failure)

Este documento contiene prompts breves para generar las imágenes de eventos: Background Images, Success Images, y Failure Images.

## 📝 Notas para Generación

- Todas las imágenes deben tener un estilo consistente de fantasía medieval
- Success images deben transmitir éxito, satisfacción y resultados positivos
- Failure images deben transmitir fracaso, decepción y resultados negativos
- Background images deben establecer el contexto y ambiente del evento
- Las imágenes deben ser adecuadas para usar como fondos en un juego visual novel
- Considerar la iluminación apropiada: más brillante para success, más oscura para failure
- Mantener coherencia visual entre imágenes del mismo tipo de building
