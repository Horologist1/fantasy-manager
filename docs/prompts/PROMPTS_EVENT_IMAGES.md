## 📝 Generation Notes

- All images must have a consistent fantasy medieval style
- Success images should convey success, satisfaction, and positive results
- Failure images should convey failure, disappointment, and negative results
- Background images should establish context and atmosphere for the event
- Images should be suitable for use as backgrounds in a visual novel game
- Consider appropriate lighting: brighter for success, darker for failure
- Maintain visual consistency between images of the same building type
