How the game picks an image

Worker art goes in game/images/workers/<folder>/, where the folder is the one named in the worker's JSON. Formats: .png .jpg .jpeg .webp .webm .mp4. Only profile is required. Every other image is optional: when a name isn't found, the game quietly moves to the next step of the chain, so a worker with just profile and skill art already covers the whole game.

Skill images

The safety net under every story, event and training session. Some skills accept several file names; any of them works. A handjob file is not recognised for Hand.

Homo: M/M scenes look for gay / homo, F/F scenes for les / homo. Gay or Lesbian workers in a story with a client outside their preference use hetero.

Daily story images

Each story names its own image. Open a row to see the full chain the game follows when that image isn't there. The relationship filter separates the stories unlocked by Romance, Relationship, Rebellious and the finale traits.

Event images

Visual novel scenes (Yvara, Varro/Varra) are not listed. Event art is searched in the acting worker's folder first, then in images/events/, which holds the shared generic_success, generic_failure and event backgrounds.

Interaction images

Exact name only (plus (N) variants). Search order: <image>_lord / _lady by player title, then _male / _female (old names), then <image>, then the category fallback, then profile. The lord/lady versions can be copies of each other, except passionate_night and perfect_night. joy_male / joy_female and romance_male / romance_female are old names: the first pair is no longer used, the second still works as a fallback.

Training images

Stricter than the rest: the file must be exactly the name below (or name (N)), with no trait prefix. Naming: Training_<Skill>_<Lord|Lady>_<Male|Female> = player title + worker gender. If it isn't there, the session shows the trained skill's image.

Adding a new worker

  1. Add the worker to any JSON file in game/data/workers/ (copy an existing one). No code changes needed. To share it, pack it as a character pack: see the Mods tab.
  2. Create game/images/workers/<folder>/ with at least a profile image.
  3. Add art in this order of value:
    • Tier 1: profile, rest
    • Tier 2: the 16 skill images and their _failure versions. With these, every job, event and training already shows something that fits.
    • Tier 3: interactions: friendship, obedience, romance_lord / romance_lady, then the specific discipline_*, friendship_*, romance_* and Training_* images.
    • Tier 4: story and event images for the jobs this worker will do. The Daily stories list above, filtered by building and profession, shows every name a job uses.
