What changed from the old guides

If you read the earlier Game Mechanics Guide or Game Reference, these are the rules that no longer hold.

Job roll

target   = average(skill_options, effective skills)
         − 10                         (Nightmare only)
         − libido distraction         (non-sexual jobs, libido ≥ 20)
         + story difficulty_modifier
         + 3 per positive trait − 3 per negative trait   (story's own weights override)
         + staff synergy (cap ±40) + policy focus
target   = min(100, target)

roll     = d100
critical : roll ≤ min(25, max(1, round(target × 0.10)))
success  : roll ≤ target
mediocre : roll ≤ target + 10
failure  : otherwise          (no_fail stories turn this into success)

One of the story's skills is picked at random to gain a use.

Effective skill

effective = min(base, 100)
          + trait skill_modifiers
          + equipped item skill_modifiers
          + floor(libido / 2)          (sex skills, NSFW on)
          + 5 × management skill        (Whore Mastery for sex skills, etc.)
          + monthly card modifier       (during jobs)

The sex skills are Sex, Anal, BDSM, Hand, Oral, Homo, Special, Group, Extreme and Striptease. The SFW skills are Combat, Clever, Charm, Service, Agility and Craft.

Earnings

pay = story formula for the outcome     ("50 + skill", "-(roll - skill)", …; skill = target)
pay × staffing      (clamped 1/3 … 3)
pay × difficulty    (Story 1.3, Easy 1.15, Normal 1, Hard 0.85, Nightmare 0.7; gains only)
pay × trait mult    (each ≤ 1.2, total ≤ 1.5; gains only)
pay × (1 + 0.1 × Business Acumen)
pay × monthly card
failure: loss halved (rounded up), then floor: Story → 0, Easy → −25

Stories per worker

effective_rep = min(reputation, level × 200) + best manager level × 200
stories       = max(1, base + reputation_formula)     base = 1, formula = effective_rep / 400
