# Templates incluidos

Plantillas listas para copiar en tus JSON de contenido:

- `buildings/profession.template.json`
- `buildings/daily_story.template.json`
- `events/event.template.json`
- `interactions/interaction.template.json`
- `workers/worker.template.json`

Tip:
- Para Academy (`academy_*`), define `daily_story_count` con:
  - `{ "base": 1, "bonus_formula": "0" }`
  para mantener 1 sesion diaria por worker.
