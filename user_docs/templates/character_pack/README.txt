MIRA - example character pack for Fantasy Manager
==================================================

Contents: 1 character (Mira), 2 traits, 1 story event, 1 recruitment scene, 1 daily story.

INSTALL - option A (recommended): in-game importer
1. Main menu > Mods > Install mods > Choose ZIP or folder.
2. Pick this ZIP, review the summary, press "Install this pack".
3. Close and reopen the game. Start a new game.

INSTALL - option B: drag & drop (PC)
1. Close the game and extract this ZIP.
2. Drag the "game" folder onto the game's main folder (the one with
   Fantasy_Manager.exe). Choose "merge". No original file is replaced.

Use ONE method only. Installing the same pack both ways makes the importer
refuse it (its events would exist twice).

UNINSTALL
- Option A: Mods > Install mods > Uninstall, then restart.
- Option B: delete these files from the game's "game" folder:
    data/workers/mira.json
    data/traits/mira_traits.json
    data/events/events_mira.json
    data/events/recruit/event_recruit_mira.json
    data/buildings/daily_story_extensions/mira_stories.json
    images/workers/Mira/   (whole folder)
